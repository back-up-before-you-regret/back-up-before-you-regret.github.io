TL;DR

Coding agents modify real-world state, such as software environments, databases, and files, and users often regret the loss later, when they find they still need it.

RegretBench grounds 205 tasks in real-world regret moments and tests whether coding agents back up, how often, and whether it matches what humans later need.

BackUpper is a plug-in that backs up affected state before every tool call, covering every regret-moment action at $0.014 per task.

01 · The problem

RegretBench: do agents back up before you regret?

Each task is built from a real regret moment: someone let an action change state they later needed, and could not get it back. The agent finishes the task; the question is whether it kept a way back.


      

      

      
    

    

      
Main result: agents finish the task, but rarely back up first

      
Across six frontier models, agents finish 86.1% of tasks, back up only 17.4% of the out-of-workspace state they change, and just 15.2% of the steps users later regretted. Five of six back up more often overall than at the regret moment, so even their backups tend to miss what users needed.

02 · The fix

    
BackUpper: back up before every tool call

    
BackUpper sits on the harness's pre-tool-call hook. It intercepts each call, backs up the state the call will change, then lets the call run. When you regret it, you restore.

    

      

      

      

      
    

    

      
Main result: every regret moment covered, on every model

      
With BackUpper, RMBR and OWBR reach 100% on all six models, and the restored state is 92.2% similar to the original on average (14.3% without restoring).

03 · Try it

    
Try it yourself: plug it into your agent

    

      

        
Install BackUpper once and keep using your agent as usual. Every tool call is checked before it runs, and the state it touches is backed up first.

        
Common operations are handled by rules at no model cost; anything else goes to a lightweight subagent. Every backup is logged with a way to restore it.

        
Tested with Claude Code, Codex, and Hermes.

      

      
      
$ npm install -g agents-backupper

# use your agent as usual
$ claude

# undo when you regret
$ backupper log
$ backupper restore <id>
